2快速上手（5 個步驟）

➕ 新增資產→ 📊 總覽確認→ 🔧 維修/🔄 轉移→ 📥 匯出盤點→ 🗄️ 定期備份
  1. 選「資產大類」與「所屬部門」：系統會自動產生資產編號（唯讀），不需手動輸入。
  2. 填寫設備名稱（必填）與其他欄位，按「確認登記此筆資產」，右下角會跳出綠色成功提示。
  3. 到總覽看板確認資料是否正確，可即時搜尋。
  4. 後續維護：需要送修用「資訊資產維修」；換保管人/部門/位置用「資訊資產轉移」。
  5. 匯出與備份：用「匯出 Excel 盤點總表」列印條碼貼紙；定期到系統管理做資料庫備份。
✅
所有操作成功都會以「右下角浮動提示」呈現，不會跳出會卡住畫面的系統對話框。

3總覽看板首頁

🔍 即時搜尋

在搜尋框輸入資產編號、設備名稱、保管人等關鍵字，下方表格會即時篩選，不需按 Enter。

📋 查看資產履歷

點擊表格中的設備名稱（藍色連結），會開啟「資產維運履歷」彈窗，內容包含：

  • 基本資料：設備名稱、大類、所屬部門、保管窗口、購買廠商、S/N、狀態、日期、位置、備註。
  • 🔧 維修紀錄：每次維修的「送修 → 完工／報廢」週期。
  • 🔄 轉移歷程：每次轉移的「部門／保管人／位置」變化，若部門未變更會標示「編號不變」。
  • 底部按鈕：✏️ 編輯修改 🗑️ 移至回收桶 📤 匯出資產履歷

📥 匯出 Excel 盤點總表

點右上角「匯出 Excel 盤點總表」，會匯出所有資產的完整盤點表，最後一欄附上資產條碼貼紙（可直接列印）。詳見「匯出與條碼貼紙」章節。

⚠️
表格可切換狀態顏色：使用中 庫存備用 維修中 已報廢

4➕ 新增資訊資產

  • 選擇「資產大類」：決定編號開頭的類別代碼（HW/SW/NET/DEV/SEC）。
  • 選擇「所屬部門」：預設為「資訊部門 (IT)」，可改成實際使用單位。
  • 系統自動產生資產編號（灰底唯讀）：格式為 類別-部門-建檔日期-流水號。
  • 填寫設備名稱（必填）、原廠序號、保管窗口、擺放地點、購買廠商、採購/保固日期。
  • 填寫「資產規格 / 備註」（選填）：可記錄 CPU／記憶體／硬碟等規格、加裝配備或其他補充資訊。
  • 按「💾 確認登記此筆資產」，右下角跳出成功提示並自動回到總覽看板。

欄位說明

欄位說明

所屬部門資訊部門(IT)、總務(GA)、病房(WA)、兒科(IN)…等，決定編號中的部門代碼

💡
新增時只需選好大類與部門，編號就會自動產生；維修中與已報廢狀態由「維修」與「報廢」流程自動管理，不需手動選。

5🔧 資訊資產維修

用來記錄資產送修到完工（或報廢結案）的完整週期。

🔧 登記維修→ 🟡 資產轉為「維修中」→ ✅ 完工→ 🟢 自動復原「使用中」
  • 選擇維修資產：可輸入關鍵字或點選下拉，選定後自動帶入目前保管人與位置資訊。
  • 填寫故障描述（必填）、維修廠商/工程師、送修日期、費用、備註。
  • 按「🔧 確認登記維修並轉為維修中」。
  • 維修完成後，在下方「維修履歷記錄總表」按 ✅ 完工，資產狀態會自動回到「使用中」。
狀態意義
🟡 維修中工單進行中，該資產在「編輯修改」時狀態會被鎖定
✅ 已完工已完成維修，資產復原為使用中
🚨 因報廢結案維修期間資產被報廢，工單自動結案
⚠️
資產在「維修中」時，到 editor 編輯修改會看到維運狀態被鎖定；這是避免與維修週期衝突，完工後即解除。

6🔄 資訊資產轉移

用於更換保管人、搬遷位置，或跨部門調撥。跨部門時系統會自動更新部門與重新編號。

  • 選擇轉移資產：輸入關鍵字或點選，會自動帶入「原部門 / 原保管人 / 原位置」。
  • 選擇「轉移後部門」（必填）：下方提示會即時告訴您是否會重新編號。
  • 填寫新保管窗口與新擺放地點（必填），可補轉移原因與備註。
  • 按「🔄 確認登記轉移並更新資產資訊」。

改號規則（重點）

情況結果
選擇相同部門只更新保管人/位置，資產編號不變
選擇不同部門依新部門重新編號，例如 DEV-IT-20261029-0001 → DEV-IN-20261029-0002
⚠️
若您要「改號」，請務必在「轉移後部門」選擇不同的部門；選相同部門是不會改號的。
💡
轉移後，於總覽點該資產的履歷，可在「🔄 轉移歷程」看到部門/保管人/位置的變化，以及是否改號。

7🏢 廠商管理

📊 廠商管理看板

新增/更新合作廠商資料，填寫服務專員、電話、地址、NDA 狀態、維護合約期間，並可上傳 NDA 與採購合約電子檔。

✏️ 廠商資料維護

先用關鍵字搜尋廠商，再修改基本資料、增補或刪除隨附文件，或徹底註銷廠商。

🗂️ 廠商維護歷程看板

記錄每次設備維護（日期、設備、類型、費用、簽收、內容），可歸檔維護單據，並匯出單一廠商維護歷程。

📝 新增廠商維護紀錄

選擇廠商與維護日期，填寫維護內容與費用，上傳單據後儲存。

  • 到「廠商管理看板」填寫廠商資料（公司名稱為必填），可一併選取 NDA/合約檔案。
  • 按「💾 儲存廠商資料」，下方名冊會即時更新。
  • 要修改或刪除，改用「廠商資料維護」：輸入關鍵字 → 選取 → 修改 → 儲存。
  • 維護紀錄請到「廠商維護歷程看板 / 新增廠商維護紀錄」登錄。
💡
廠商相關操作使用「站內提示」與「站內確認視窗」，不會跳出會卡住畫面的系統對話框。

8🗑️ 資源回收桶

資產不想直接刪除時，可先「移至回收桶」（軟刪除），之後仍可還原。

  • 在總覽看板點設備名稱開啟履歷，按「🗑️ 移至回收桶」並確認。
  • 該資產會從總覽消失，但資料仍保留在「🗑️ 資源回收桶」。
  • 若誤刪，到資源回收桶按「🔄 還原」，資產會回到總覽看板。
⚠️
回收桶是「隱藏」而非永久刪除；但從回收桶還原前，請確認沒有重複建立同一台設備。

9⚙️ 系統管理

🗄️ 資料庫備份

  • 📦 資訊資產資料備份：只備份資產相關資料。
  • 🏢 廠商資訊資料備份：只備份廠商相關資料。
  • 💾 全備份：備份所有資料表（建議定期執行）。
  • 📎 附件檔備份：將 uploads 內的 NDA/合約/維護單據打包成 zip。

♻️ 資料庫還原

選擇對應的備份檔還原。系統會先自動建立「還原前備份」作為保險，再以備份內容覆蓋。

🔄 版本更新

  1. 按「🔍 檢查最新版本」連線更新伺服器讀取 latest.json。
  2. 若有新版，按「⬇️ 下載更新檔」下載並驗證 SHA256。
  3. 按「🚀 安裝並重新啟動」進行安裝（安裝前會自動全備份）。

📥 匯入資料表

可用 Excel 範本批次匯入資產或廠商資料；匯入前會先顯示「新增/更新/略過/失敗」統計，再次確認後才寫入。

資產範本已包含「資產規格/備註」欄位，可直接批次填入規格資料；匯入後同樣會出現在總覽、履歷與盤點總表。

⚠️
「還原」會覆蓋目前資料，務必先確認備份檔正確。重大操作前建議先做一次「💾 全備份」。

10🧩 欄位管理

位置：⚙️ 系統管理 → 🧩 欄位管理（系統管理的第一項）。可自行新增／移除「資產大類」與「所屬部門」的選項，讓不同產業（醫院、學校、公司…）都能使用自己的分類。

💡
可自行新增／移除「資產大類」「所屬部門」選項；名稱可中文、代號請用英數（1~8 碼），代號會用於資產編號（例：HW、MON、IT）。

➕ 新增選項

  • 左側清單是「🏷️ 資產大類」，右側是「🏢 所屬部門」，兩邊操作方式相同。
  • 在「名稱（可中文）」輸入要顯示的文字，例如 監視器、放射科。
  • 在「代號（英數）」輸入 1~8 碼英文或數字，例如 MON、RD（系統會自動轉大寫）。
  • 按「➕ 新增」，右下角出現成功提示，清單與所有下拉選單立即更新（新選項排在清單最後）。

🗑️ 刪除選項

  • 在清單右側按「🗑️ 刪除」，於確認視窗按確定即可移除。
  • 刪除後，該選項會從「新增資產／編輯資產／資產轉移」的下拉選單中消失。
  • 已建立的資產不會被修改或刪除，其原本的大類／部門與資產編號都維持不變。

代號的用途（重要）

用途說明
資產編號大類代號 + 部門代號 + 建檔日期 + 流水號，例如 MON-IT-20261029-0001
轉移改號跨部門轉移時，系統會用新部門的代號重新組成編號
匯出／履歷匯出的 Excel 以「名稱 (代號)」呈現，例如 監視器 (MON)
⚠️
代號必須是 1~8 碼英文或數字，不可使用中文、空白或符號，且同一類別內不可重複；建議用看得懂意思的短代碼（例：NB 筆電、PRN 印表機）。
ℹ️
清單固定高度、可上下捲動（表頭固定）。目前尚無「修改」功能，若要調整既有選項，請先刪除再新增一筆；既有資產資料不受影響。

11🔢 資產編號規則

格式：類別 - 部門代號 - 建檔日期 - 流水號，例如 NET-IT-20261029-0001（資訊部門的網路設備）。

類別代碼

資產大類代碼範例
硬體設備HWHW-IT-20261029-0001
軟體授權SWSW-IT-20261029-0001
網路設備NETNET-IT-20261029-0001
資訊周邊DEVDEV-IT-20261029-0001
帳密安全性SECSEC-IT-20261029-0001

部門代碼

IT 資訊部門DR 院長室,醫師辦公室TL 督導 GA 總務MO 行政PT 主任 AC 人事,會計CK 廚房SM 倉庫 WO 工務LA 檢驗室OP 婦科 IN 兒科PO 警衛OR 產房 WA 病房HE 申報BR 嬰兒室 CH 病歷室CO 櫃台P1 藥局

💡
上表的類別代碼與部門代碼為預設值，可到「⚙️ 系統管理 → 🧩 欄位管理」自行新增或移除；該處設定的代號就是編號中使用的代碼。

流水號

  • 依「同類別 + 同部門」自動遞增（取現有最大流水號 +1），不受建檔日期影響。
  • 例如同為資訊部門的硬體設備：HW-IT-…-0001、HW-IT-…-0002、HW-IT-…-0003。
  • 編號由系統自動產生且唯讀，建立後不可手動修改；轉移時若跨部門會自動重新編號。
💡
建檔日期為「建立當天」，流水號在「同類別+同部門」內保證唯一且遞增。

12📥 匯出與條碼貼紙

匯出 Excel 盤點總表（全部資產）

  • 到「📊 總覽看板首頁」，點右上角「📥 匯出 Excel 盤點總表」。
  • 選擇儲存位置，系統會匯出所有資產的完整盤點表。
  • 表格包含「資產規格/備註」與「備註事項」兩欄，方便列印時一併核對規格。
  • 最後一欄為「資產條碼 (貼紙)」：上方顯示資產編號，下方為 Code 128 一維條碼。
  • 列印貼紙時建議將縮放設為 100%，以確保條碼清晰可掃。

匯出單筆資產履歷

在資產履歷彈窗按「📤 匯出資產履歷」，會產出三個工作表：資產基本資料、維修紀錄、轉移紀錄（基本資料含「資產規格/備註」與「維運備註」區塊）。

✅
盤點總表的條碼採用「隨儲存格移動及縮放」錨定，用「部門」欄篩選時，條碼會跟著對應列一起隱藏/對齊，不會錯位。
⚠️
請使用最新版程式重新匯出；舊檔的條碼錨定方式不同，篩選後可能位移。

13❓ 常見問題

Q1：按「確認登記」後，為什麼右下角只出現提示、沒有彈出視窗？

本系統改用「站內浮動提示」取代系統對話框，避免視窗卡住，屬正常行為。

Q2：轉移後編號沒有改變？

因為「轉移後部門」選了與目前相同部門。系統只有在部門改變時才重新編號；若要改號，請選擇不同部門（表單下方會有即時提示）。

Q3：資產維修中，為什麼不能改維運狀態？

為避免與維修週期衝突，維修中的資產在編輯時狀態會被鎖定；到「資訊資產維修」把工單標記完工後即可恢復。

Q4：資產不小心刪除了怎麼辦？

到「🗑️ 資源回收桶」找到該資產，按「🔄 還原」即可。

Q5：如何備份與還原資料？

「⚙️ 系統管理 → 🗄️ 資料庫備份」定期做全備份；需要時用「♻️ 資料庫還原」選擇備份檔還原。

Q6：條碼貼紙列印出來模糊或掃不到？

列印時縮放請設 100%、使用雷射印表機、避免過度縮小；貼紙裁切時請保留條碼左右空白區。

Q7：新增資產時，選單裡找不到我要的大類或部門？

請先到「⚙️ 系統管理 → 🧩 欄位管理」新增該選項（填「名稱」與「英數代號」），按「➕ 新增」後，新增資產／編輯資產／轉移的下拉選單會立即出現該選項。
